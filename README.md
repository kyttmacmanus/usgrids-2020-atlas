# USGRIDS 2020 — Scientific Review Preview

A static scientific atlas for review of the corrected 2020 Census allocated-grid release candidate. This is a preview, with archive citation, individual authorship, affiliations, funding, rights and DOI still being finalized. No Dataverse deposit or final dataset publication is claimed.

The full site contains 53 geographic selections, 31 canonical variables, 1,643 geography-variable pairs and 4,823 existing validated map views. Maps, exact class thresholds, full-resolution frequencies, valid-cell denominators and scientific identities are retained; this repository performs no raster processing, map rendering or statistics computation.

The public source catalog has 1,956 scientific product identities. Scientific GeoTIFFs, NetCDFs, Shapefiles, historical scripts, internal QA archives and credentials are not included. Repository registration and the approved final archive inventory remain pending. Curated methods/dictionary/limitations remain available without external archive downloads.

Open site/review.html through any local static HTTP server to review. See ALEX_REVIEW_GUIDE.md. tools/verify_site.py checks the static manifest and all map references with Python's standard library.

The Pages workflow is manual only and has no push trigger. Its input and PUBLIC_VISIBILITY_APPROVED repository variable must both be true, after actual owner/institution clearance. Configure required reviewers on the github-pages environment before enabling deployment. Never enable these gates merely because local checks pass. The hosted workflow packages site/ only; it does not rebuild maps. No essential asset uses Git LFS.

No license is assigned by this preparation. A preview label does not settle rights. Do not push this source to a public repository or deploy publicly until the owner has explicitly approved this exact audited preview and its rights/attribution basis. Final data publication and any later archive links require their own approvals.
