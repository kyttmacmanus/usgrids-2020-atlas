# USGRIDS 2020 vector identity

Concept 2 direction: regular gridded CONUS with distinct Alaska, Hawaii and Puerto Rico panels. Different inset scales are intentional. This is a schematic identity, not original raster values or a scientific map. Editable SVG paths and live wordmark text are the source.

Coarse outlines are derived only from the alpha footprint of the existing validated national shared-quintile display `assets/maps/NATIONAL_TOTALPOP_shared.webp`, SHA-256 `0c1c6702e67a713e7aedf968653bac3733d510f5c13ee211f9d8f31fd669a2c6`. Display-mask simplification removes small speckles; no scientific mask is modified. No new geographic territories are introduced.

Primary and navigation marks use #163770; restrained cells use #EED649. Explicit dark variants use #F7F5EE. The monochrome SVG uses currentColor; inline it to inherit a document color. The favicon uses a simplified gridded mainland subset for small sizes.

UI palette: navy #163770 and slate #555B6D are exact existing quintile colors; gold #EED649 is the exact upper-quintile color. Paper #F7F5EE is a near-white tint informed by the fixed palette's #FFF3C4 and white. Link gold #866214 is a contrast-darkened UI accent. Lines #CED3DC and notice #EDEEF0 are neutral slate tints. None replaces a scientific class color.
